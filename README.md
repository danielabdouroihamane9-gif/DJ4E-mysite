# DJ4E - Django for Everybody

This repository contains my coursework and web applications built during the "Web Application Technologies and Django" (DJ4E) course. 

## Project Structure
* `mysite/`: The core Django project directory containing settings and routing.
* `polls/`: A polling application built following the official Django tutorial and DJ4E curriculum.

## Tech Stack
* Python 3
* Django 5
* SQLite
* Hosted on PythonAnywhere
